A high-fidelity clothing modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** introducing the Reverse Bunny Suit outfit with modular components.

---

## 🎮 Features

- **Multiple Suit Cuts:**
  - Standard Cut Reverse Bunny Suit.
  - High Cut Reverse Bunny Suit variation.
- **Matching Accessories Included:**
  - Long Gloves (Left & Right).
  - Long Socks (Left & Right).
  - Reverse Bunny Top & Bottom sections.
- **Multilingual Localization Support:** Built-in translations for English, Russian (`ru`), and Simplified Chinese (`zh-Hans`).
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.96.7`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/reverse-bunny-suit/releases) page and download `reversebunny suit 1.2.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `reversebunny suit 1.2.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/reverse bunny suit/mod.json
   ```
4. Launch the game and purchase/equip the outfit from the Clothier.
