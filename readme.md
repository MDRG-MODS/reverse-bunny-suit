A high-fidelity clothing modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** introducing the Reverse Bunny Suit outfit with modular components.

---

## 🎮 Features

- **Multiple Suit Cuts:** Standard Cut and High Cut Reverse Bunny Suit variations.
- **Modular Pieces:** Long Gloves (Left & Right), Long Socks (Left & Right), Top & Bottom sections.
- **Multilingual Localization:** Built-in translations for English, Russian (`ru`), and Simplified Chinese (`zh-Hans`).
- Compatible with MDRG version **v0.97.12** (Target: `0.96.7`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/reverse-bunny-suit/releases) tab.
